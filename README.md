# From the Sphere to the Hill: project page

Source of https://sphere-to-hill.github.io, the project page of the NeurIPS 2026 paper "From the Sphere to the
Hill: Closed-Form Anchors for Boundary-Integral Surrogates on Real Terrain" by Stephane Zsoldos, Therice
Morris, Varundev Sukhil and Benjamin Wetherfield.

The page is static, with no build step and no external requests: `index.html` and `static/`. To view it
locally, open `index.html`, or run `python3 -m http.server 8000` in this folder and visit
http://localhost:8000.
